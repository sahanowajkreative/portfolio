# Sahanowaj Developer Portfolio (React)

## Important: do not open `index.html` by double-clicking it
This is a React + Vite project. Run it through the development server.

## Requirements
- Node.js 18 or newer
- npm (included with Node.js)

## Run locally
1. Extract this ZIP file.
2. Open the extracted `sahanowaj-portfolio-react` folder in VS Code.
3. Open **Terminal → New Terminal** in VS Code.
4. Run these commands one by one:

   ```bash
   npm install
   npm run dev
   ```

5. Open the local URL printed in the terminal (usually `http://localhost:5173/`).

## Create a production build
```bash
npm run build
```
The production-ready files will be created in the `dist` folder.

## Before publishing
In `src/main.jsx`, replace `your-email@example.com` with your real email address.
